# MyBatis
## What is MyBatis?
- MyBatis is an excellent persistence framework that simplifies JDBC development.
- MyBatis was originally an open-source project called iBATIS under Apache. In 2010, it was migrated from the Apache Software Foundation to Google Code and renamed MyBatis. In November 2013, it was moved to GitHub.
- Official Website: https://mybatis.org/mybatis-3/

## Persistence Layer
- The persistence layer is responsible for storing and retrieving data from the database.

**In the traditional Java EE three-layer architecture**:
- Presentation Layer
- Business (Service) Layer
- Persistence (Data Access) Layer

## Framework
- A framework is a reusable software foundation that provides a common structure for building applications.
- It offers reusable components and best practices, making software development more efficient, standardized, maintainable, and scalable.
